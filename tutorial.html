🔍 Address Bar Shortcuts

Pull the domain from any URL and search the Meta Ads Library in one go:

Type @ads + Space + any URL, then hit Enter.

@ads https://example.com/shoes
→ searches the Ads Library for example.com

🖱️ Right-Click & Quick Search

  • From any page: select some text, right-click, and choose "Search Ads Library for..."

⬇️ Meta Ads Downloader

Inside the Meta Ads Library you'll spot quick download buttons right on ad images and videos. Save creatives straight to your computer!
